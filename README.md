# 🌍 About

Lettercraft started from a simple habit in our small Discord server, **Runeterra** — a close-knit circle of friends scattered across different countries.

Whenever a birthday, anniversary, or any occasion came up, we'd scramble to find some online card maker to send something thoughtful across the miles.

Eventually the question became:

> *Why not just make our own?*

Something more personal.  
Something more flexible.  
Something a little more *us*.

And that's how Lettercraft was born — a handcrafted letter maker built with the same spirit of sending something warm to someone far away.

---

# 🌏 Runeterra

Runeterra isn't a game server or a fan club — it's simply our little corner of the internet.

Friends from different countries and timezones who somehow ended up in the same Discord, celebrating each other's highs and showing up through the lows.

This tool exists because of them.

# 📥 How to Use Lettercraft

1. Download the generated HTML file named:

Lettercraft by Yukjidam.html

2. Open the file using any modern web browser.

Supported browsers include:

- Google Chrome
- Microsoft Edge
- Firefox
- Opera
- Safari

No installation, server setup, or internet connection is required after downloading.

You can also send the HTML file to someone else so they can open and experience the letter exactly as intended.
